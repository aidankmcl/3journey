# Three.js Journey Course

This repository holds code from all the lessons I worked through for Bruno Simon's [Three.js Journey](https://threejs-journey.com/) course, which I highly recommend to anybody looking to learn Three! He is actively maintaining and adding to the course on top of making himself available in the associated Dicord - overall it's an excellent value for everything you get.

This repo also contains a couple of mini-projects that I worked on along the way. These are mostly explorations of some specific concept rather than complete 3D experiences.
